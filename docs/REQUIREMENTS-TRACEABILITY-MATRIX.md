# Requirements Traceability Matrix — PRD Situs Astro

> Versi 1.0 | 2026-11-28 | Status: baseline traceability

## 1. Aturan penggunaan

Setiap persyaratan normatif diberi ID stabil. Baris dinyatakan **terlacak** bila sumber normatif, aturan implementasi, bukti test/verifikasi, dan kriteria penerimaan terisi. Jangan menghapus persyaratan yang belum diimplementasikan; tandai sebagai gap.

Jenis bukti:
- **AUTO**: test otomatis yang benar-benar ada pada repository standar.
- **PROJECT**: test yang wajib ditambahkan dan dijalankan pada setiap situs Astro karena bergantung pada implementasi/hasil render proyek.
- **MANUAL**: review/approval manusia.
- **DOC**: pemeriksaan kelengkapan dokumen dan keputusan.

Nama test AUTO di bawah adalah nama fungsi pada `tests/test_validate_content.py`. Test repository standar tidak membuktikan build Astro, aksesibilitas hasil render, atau persetujuan editorial.

## 4. Batas bukti baseline

Repository standar menyediakan validator referensi dan test otomatis untuk kontrak, ID, relasi, schema/block registry, route, aset/link, manifest, dan extension contracts. Workflow standar menjalankan smoke test CLI dan pytest. Repository ini bukan aplikasi Astro turunan; karena itu tidak mengklaim production build, accessibility browser, rendered SEO/JSON-LD, relevansi IA, atau editorial approval telah dilakukan pada situs tertentu. Proyek pengadopsi wajib mengisi bukti PROJECT/MANUAL dalam CI dan release record-nya.

## 5. Kriteria kelengkapan matriks

- Semua baris memiliki empat dimensi traceability.
- Nama test AUTO benar-benar ada pada test suite.
- Test PROJECT/MANUAL tidak diklaim sudah dijalankan pada repository standar.
- QG-01 sampai QG-13 memiliki requirement terkait dan bukti minimum.
- Setiap perubahan dokumen normatif memperbarui matriks dan bukti terkait.
